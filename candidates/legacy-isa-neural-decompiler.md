# Candidat : Neural Decompiler Legacy ISA

* **Domaine principal :** Cybersécurité & Résilience
* **Modèle économique :** B2B / B2G
* **Cible :** Secteur bancaire, compagnies aériennes, gouvernements et armées (utilisant des mainframes IBM, systèmes embarqués militaires, ou vieux systèmes de contrôle ferroviaire).
* **Le problème urgent :** Des infrastructures critiques mondiales (systèmes de paiement, radars militaires, contrôles de vol) tournent sur du code compilé pour des architectures de jeux d'instructions (ISA) obsolètes des années 70/80. Les codes sources originaux sont souvent perdus, et les ingénieurs capables de lire ce binaire disparaissent. L'impossibilité de décompiler fidèlement et d'auditer ces binaires legacy empêche l'application de patchs de sécurité modernes, laissant ces systèmes vulnérables à des exploits bas niveau critiques.
* **L'approche technique :** Développement d'un "Neural Decompiler" basé sur un grand modèle de langage spécialisé (LLM) entraîné exclusivement sur des paires (code binaire legacy / code source C ou Rust) via des techniques de Deep Learning for Code (CodeBERT adaptatif). Le moteur ingère le binaire d'architectures mortes (ex: PDP-11, vieilles architectures MIPS ou architectures propriétaires non documentées) et génère une représentation sémantique intermédiaire (IR) puis un code source pseudo-C fonctionnellement équivalent et structuré.
* **Pourquoi une solution générique/SaaS classique échoue :** Les décompilateurs classiques (comme Ghidra ou IDA Pro) utilisent des règles heuristiques rigides. Ils échouent lamentablement face à du code fortement optimisé, obfusqué ou issu de compilateurs très anciens aux standards non-respectés. Seule l'IA peut déduire des motifs complexes ("pattern matching" sémantique) là où les règles formelles échouent.
* **Risques majeurs & Dépendances :** La "hallucination" du modèle est inacceptable dans ce domaine : si le code décompilé est fonctionnellement différent du binaire de 0.01%, le système critique crashe. La génération de données d'entraînement synthétiques fiables pour des architectures mortes est extrêmement ardue et coûteuse.
